# Request context

Include this optional header in requests:

```text
Access context: GPT
Project: HackerRank Orchestrate — Ghost Data Still Exists
Task: <desired outcome>
Constraints: <scope or priorities>
```

Agents ask for the interface once per session when missing and carry the user's answer into request logs. This does not request physical location. User-reported interface, actual agent harness and runtime model are separate fields.
